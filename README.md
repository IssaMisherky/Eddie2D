This library is mainly developed to help indie game developers with getting their NPC to the next level without all the complications behind it.

- Motion simulations.
- Path finding.
- GOAP system.

These three systems are combined into a single library so that you can expand your NPC's behaviours. You can find the full documentation [here](rhythmrate.com/eddiedocs/).
